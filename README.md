# Отчет по лабораторной работе №2: Основы NumPy и векторные операции

## Описание задачи
В данной лабораторной работе требовалось изучить основы работы с библиотекой NumPy для языка Python. Основные задачи включали:
1. Создание и изменение формы векторов и матриц.
2. Реализация векторных и матричных операций без использования циклов (векторизация).
3. Применение линейной алгебры (определитель, обратная матрица, решение СЛАУ).
4. Статистический анализ данных успеваемости студентов и нормализация данных.
5. Визуализация данных (построение гистограмм, тепловых карт корреляции и графиков).

Код должен был строго соответствовать стандартам PEP-8, содержать аннотации типов (PEP-484) и документацию (PEP-257).

## Как была решена задача
Задача была решена путем написания функций в файле `main.py` с использованием встроенных методов библиотек NumPy, Pandas, Matplotlib и Seaborn:
- Использованы функции `np.arange()`, `np.reshape()`, `np.linalg.solve()`.
- Статистика посчитана с помощью `np.mean()`, `np.median()`, `np.std()`, `np.percentile()`.
- Построены графики и сохранены в директорию `plots/` с помощью `plt.savefig()`.
- Все реализованные функции успешно прошли автоматическое тестирование через `pytest`.

## Нюансы при решении
1. **Типизация данных:** Некоторые тесты ожидали стандартный тип данных Python (`float`), поэтому пришлось явно приводить результаты вычислений NumPy (например, `numpy.float64`) к базовому типу `float()`.
2. **Активация окружения:** В Windows PowerShell потребовалось временно изменить политику безопасности `Set-ExecutionPolicy Unrestricted -Scope Process`, чтобы разрешить запуск скрипта активации виртуального окружения.
3. **Директории сохранения:** При генерации графиков средствами `matplotlib` потребовалось использовать модуль `os` для автоматического создания папки `plots`, если она отсутствует.
